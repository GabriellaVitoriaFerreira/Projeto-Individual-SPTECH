## Sobre o projeto

Este projeto é uma homenagem ao meu filme preferido: **"Retrato de Uma Jovem em Chamas"** (*Portrait de la jeune fille en feu*).

A escolha do tema partiu do que eu gosto. A representatividade LGBT e a forma sensível como o filme constrói uma história de amor e arte foram o que o tornaram o meu favorito. A ideia do site é compartilhar essa experiência: apresentar a história, explicar por que o filme é importante para mim e deixar o visitante interagir com ele por meio de um quiz e de uma tela de pintura.

---

## Objetivos

- Apresentar o filme de forma sensível e organizada, dividido em atos.
- Contar por que essa obra é importante para mim.
- Criar uma experiência interativa (quiz e pintura de quadro).
- Praticar os fundamentos de desenvolvimento web aprendidos no 1º semestre: front-end, back-end básico e visualização de dados.

---

## Funcionalidades e escopo

### Página inicial (One Page)

Uma página única, com navegação por âncoras, dividida nas seguintes seções:

| Seção | Descrição |
|---|---|
| **Página inicial** | Apresentação do projeto e do filme |
| **Importância do filme para mim** | Relato pessoal sobre o que a obra representa |
| **Ato 1** | Primeira parte da história do filme |
| **Ato 2** | Desenvolvimento da história |
| **Ato 3** | Desfecho da história |
| **Personagens** | Apresentação dos personagens principais |
| **Âncora / Footer** | Rodapé com âncora e créditos |

### Login e Cadastro

- Tela de **cadastro** para novos usuários.
- Tela de **login** para acesso às áreas interativas.

### Página interativa

- **Quiz** sobre o filme.
- **Pintura de quadro:** uma seção onde o usuário pode criar a sua própria pintura, inspirada na arte presente no filme.

### Dashboard

- Painel construído com **Chart.js**.
- **Acesso restrito:** disponível apenas para mim (administrador), não para o usuário geral.

## Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- [Git](https://git-scm.com/) instalado

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git

# 2. Entre na pasta do projeto
cd NOME-DO-REPOSITORIO

# 3. Instale as dependências
npm install

# 4. Inicie o servidor
node app.js
```

Depois, acesse **http://localhost:3333** no navegador
